# samurai-desktop 4-r16 candidate

Status: signed and built, not installed.

This package removes the retired `samurai-powerkey` Python bridge and its
OpenRC service. The physical power key and DPMS policy are left to the
official KWin/PowerDevil path:

- elogind `HandlePowerKey=ignore`;
- KWin `DpmsInputEventFilter`;
- PowerDevil mobile default `PowerButtonAction=ToggleScreenOnOff` (128).

The package keeps only:

- `/usr/share/samurai/plasma-mobile`;
- `/usr/libexec/samurai-tinydm-stop`;
- the tinydm migration hook.

## Install after the panel fix

The device does not yet trust this new local key. For a bounded candidate
test:

```sh
scp samurai-desktop-4-r16.apk root@PHONE:/tmp/
ssh root@PHONE
apk add --allow-untrusted --no-network /tmp/samurai-desktop-4-r16.apk
apk info -e -v samurai-desktop
rc-service samurai-powerkey status 2>&1 || true
test ! -e /usr/libexec/samurai-powerkey && echo bridge-removed
```

For a production install, import the public key into `/etc/apk/keys` and
install the index instead of using `--allow-untrusted`.
