Its five actual-function cases cover the good pair and separately missing/different hashes in either receipt. The reviewed host calls the frozen completed-activation API and pure stage reviewer before producing a payload. The collection-only guard projects the authenticated stage transaction and source boot/board fields while retaining the actual activation transaction and full raw guard separately; `guard_sha256` names that original activation guard, not the projection. The six probe identity functions are exact extracts from the frozen device collector. Both probe identities must match the same new boot and differ from the source boot. The original key/endpoint/argv, original PID and birth ticks, actual integer terminal code, stdin digest and output hashes bind each distinct probe/collector transfer. Collection uses the execute/window/new-endpoint command, rather than the probe-only default command.

On success, the host recomputes all ten checks through the frozen actual device audit, compares that complete result with the device response and requires both capture identities to equal the actually probed new boot. Collection exceptions, failed audit, malformed output or lost/incorrect receipt cannot become a passed result; this reader never deletes raw evidence. Missing real completion/probe materials are rejected before bind creates its output directory. The source-only CLI and narrow R2 source check receipts are actual terminal-zero records, not evidence of a runtime transaction.

The final `review-result.json` binds R2 sources/receipts and verifies the exact R1→R2 source delta, archived R1 identity, six extracted functions and frozen dependencies without rerunning the 5/18/13/31 suites. USB, stage/completion and IO boundaries in the author tests remain explicitly fake. No actual request, guard, endpoint verification, capture, device operation, build, SDK or Git action occurs in this review. Static registration, boot flash completion and postboot health do not establish physical IRQ delivery, charging-icon latency or complete rootfs rollback; those conclusions remain outside this leaf.
