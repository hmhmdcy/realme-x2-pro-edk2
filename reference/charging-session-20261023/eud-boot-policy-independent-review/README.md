The new event has independent static context, an exact BeforeExitBootServices GUID and TPL_CALLBACK. Arm failure skips the kernel call and reaches original cleanup. The actual CoreExitBootServices source signals BeforeEBS before stopping the timer and checking MapKey; actual TPL dispatch does not reenter equal-priority callbacks. All three original panel functions and their original call block are byte-identical.

CSR access is the existing BDS address `0x088e1014`, width 32 bits. Only complete old values 0/1 are accepted, and complete readback 0 is required for EFI_SUCCESS. The unsupported `0x01010101` replica was correctly withdrawn by the v2 amendment. No AHB/PHY/SCM/budget operation is added. Current SerialPortLib appends RAM only; direct BDS FIFO writes stop after Attempted. EudLog's timer has no enable write and skips after verified CSR0, but a failed write/readback that still leaves low byte 1 can allow the timer to keep writing until timer shutdown. The void callback cannot veto successful ExitBootServices or prevent Linux from continuing. Therefore Attempted, failed readback or Linux startup are never evidence that all producers stopped or EUD was disabled.
