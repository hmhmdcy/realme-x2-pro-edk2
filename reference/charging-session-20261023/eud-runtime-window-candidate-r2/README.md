# EUD software quiet window R2: join late producers before release

Offline review candidate; no consumer or automatic activation. The only R1 source change is in `eud_remove_locked`: after console unregister and UART port removal have joined their producers, join RX and TX work again, for both ordinary and borrowed removal. The original early joins remain. R1 source, nine-group result, object and independent reviewer artifacts remain frozen in their original directories.

The independent [R1 counterexample](../../charging-oem-audit-20261023/eud-runtime-window-review/late-remove-counterexample/result.json) proves a legacy console callback can pass the work-kick gate, pause, then enqueue RX after the early cancels while unregister waits for that callback. R1 then clears the endpoint with RX pending. The related ordinary removal path has the same late RX gap. Final joins belong after withdrawal of all producers, before AHB restoration, mapping release or global pointer clearing. They also cover a TTY `start_tx` caller that passed its gate before UART withdrawal.

`test-result.json` records four new actual-function groups, with pthread-controlled pauses before actual queue submission: borrowed legacy RX, ordinary atomic RX, ordinary threaded nbcon RX and ordinary late TTY TX. Each callback is joined by the modeled console/UART withdrawal before final work joins; all assert no RX/TX pending when the endpoint is cleared. The borrowed case preserves the orphan cookie and leaves AHB state alone; ordinary cases preserve original AHB restoration. ASan/UBSan/Werror passed. The tests do not run queued work after free, do not prove every kernel interleaving and do not rerun the old nine or independent five groups.

Only output/dependency/temp paths changed; selected shared config/generated-header/object/command hashes stayed unchanged. The original approved storage helper located the existing mounted build. No make, SDK, shared source write, kernel/module link or hardware operation occurred.

All [R1 component and owner interfaces](../eud-runtime-window-candidate/README.md) remain unchanged: no CSR/AHB2PHY writes by the software window, no electrical routing or USB500 claim, exact-cookie cancel/end, terminal remove with orphan acknowledgment, PM interlocks and no cross-component lock nesting.
