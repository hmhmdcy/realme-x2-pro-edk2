# 最小温控恢复修复接口与定向案例

这是供根会话整合的接口建议，没有改生产实现。Full／周期计时由 `session_persistence` 支线处理，双方已确认不采用“跨boot永久过期”作为默认行为；真实既有超时／I/O／电气故障不能由 Full 清除。

## 建议接口

`sm_policy` 在已有 target 外再明确输出失败原因，至少区分以下原因；可使用 `enum sm_inhibit_reason *reason`，也可用非冲突专用返回码。不要以裸 `-ERANGE`／`-EOVERFLOW` 一概决定是否清锁。

| 原因 | 来源 | 行为 |
| --- | --- | --- |
| source allowance | 无连接／配置中的USB预算不明确 | 保留当前既有自动恢复逻辑，不清旧硬fault |
| temperature outside profile | 精确的 `!b` 分支 | 立即暂停；新鲜有效数据恢复且通过温度迟滞后可恢复，不清硬fault |
| temperature-band voltage limit | 合理电芯电压高于当前温区 OVP，例如25℃4.3V电芯进入44℃暖区 | 立即暂停；仅当前温区电压条件重新满足后恢复；不能抬高该温区CV/OVP，不能忽略真实Safety/PF |
| bad acquisition／electrical fault | 无效MAC／总线、整包一致性、全局电芯合理域、Safety/PF、REG14、写入失败 | 继续锁存，温度或源预算恢复不能清除 |
| charge-cycle timeout | 真实未完成充电周期达到10小时 | 继续锁存，不因Full／温度恢复而清除 |

核心现在先验证全局域／一致性，再选温区；应保留这一顺序，保证坏采集不被“温控暂停”掩盖。暂停可以有可恢复 reason，但既有 `c->latched` 必须按逻辑 OR 保留。

在上述范围外，两芯差和全包一致性200mV是当前工程采集检查，不能改称原厂均衡或绝对电芯安全标定。

## 外部温度门限的最小迟滞

在保留现有半开温区的前提下，可以先只迁移 OEM 的外界热／冷恢复迟滞：

- 首次 `temp >= 530` 暂停；温度回落到不高于510后才解除热暂停。
- 首次 `temp < -20` 暂停；温度回升到不低于0后才解除冷暂停。
- 热暂停期间直接跳到冷区要改为冷暂停，反之亦然，不能经过一个“允许”周期。
- 读取无效不修改温度历史；有效温度也只解除温控 reason，不能清其它 reason。
- 内部44℃等温区仍受实际温区CV/OVP限制。该最小门限并不等同复刻原厂4174–4266行所有内部方向迟滞；如果要完整复用，需按已判定温区和前温度调整各边界，不能统一将每个区间简单扩展2℃。

这里的 510／0 来自原厂2℃防抖，53℃初始停止由当前半开区间保留；原厂的热区比较是严格 `>` 而当前53℃即停止，修复无需为了边界一致而推迟停充。

## 受影响定向案例

以下是待整合代码必须满足的行为案例，尚未在修复后实现上执行：

| 顺序输入 | 预期 |
| --- | --- |
| valid25℃→53℃→52.9℃→51.1℃→51℃，无其它fault | 首次53℃立即停；51.1℃仍停；51℃新鲜全有效时恢复 |
| valid25℃→−2.1℃→−1℃→−0.1℃→0℃，无其它fault | 首次低温停；0℃前保持；0℃新鲜全有效时恢复 |
| 热暂停→−3℃→−1℃→0℃ | 全程保持停止至最后0℃；不瞬时恢复 |
| 冷暂停→54℃→52℃→51℃ | 全程保持停止至最后51℃；不瞬时恢复 |
| 温控暂停→MAC校验失败→温度正常 | MAC错误仍锁存；正常温度不能自行复位 |
| 温控暂停→REG14非零→温度正常 | 电气fault仍锁存 |
| 有旧电气锁存→温控暂停→正常 | 旧锁存保持 |
| 超时已锁存→Full→温度正常 | 真超时保持，Full不清故障 |
| 25℃／4.3V芯→44℃／4.3V芯→25℃／4.3V芯，Safety/PF始终0 | 暖区立即停；回25℃且其它条件全部正常可恢复，CV不超过原继承值 |
| 25℃／4.3V芯→44℃／4.3V芯→44℃／4.139V芯，无其它fault | 暖区过压抑制；重新低于阈值后依暖区4.130V目标恢复；不得使用正常区4.4V目标 |
| 温区正常但电芯1.9V／整包差异常 | 必须继续拒绝／锁存，不得通过温控可恢复路径 |
| 电芯或REG14读取失败同时温度越界 | 读取失败不得被温控抑制掩盖 |

Full／再充另应验证：实际REG13 Full且全样本／保护正常才结束本轮，短暂“非充电”或SOC100不能结束；再充新周期累积；暂停/USB重配置不擦除未完成周期；跨boot按OEM初始化语义处理，不因旧boot记录直接永久到期。
